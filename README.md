**Algoritmos 61 a 70 em Kotlin**

Este repositório contém os algoritmos de 61 a 70, originalmente escritos em Portugol e convertidos para Kotlin.

O objetivo da atividade é praticar a linguagem Kotlin e entender como aplicar operações matemáticas, variáveis, entrada e saída de dados e estruturas condicionais.

**Algoritmos desenvolvidos**

* Algoritmo 61: Calcula o quinto termo de uma progressão geométrica.
* Algoritmo 62: Calcula o preço de um produto com 9% de desconto.
* Algoritmo 63: Calcula o salário líquido de um professor.
* Algoritmo 64: Converte uma temperatura de Celsius para Fahrenheit.
* Algoritmo 65: Calcula o volume de um cilindro.
* Algoritmo 66: Calcula a quantidade de combustível utilizada em uma viagem.
* Algoritmo 67: Calcula o valor de uma prestação em atraso.
* Algoritmo 68: Troca os valores de duas variáveis.
* Algoritmo 69: Converte uma fração em número decimal.
* Algoritmo 70: Calcula o valor de uma conta de restaurante com 10% de gorjeta.

**Comentários sobre os exercícios**

Neste bloco, consegui praticar diferentes operações matemáticas e trabalhar mais com números decimais utilizando o tipo Double.

Também aprendi a utilizar uma variável auxiliar para trocar valores, a formatar resultados com duas casas decimais e a evitar a divisão por zero.

Os exercícios ajudaram a entender melhor como transformar os comandos do Portugol em Kotlin, mantendo a lógica original dos algoritmos.

**Ferramentas utilizadas**

* Kotlin
* IntelliJ IDEA
* Git e GitHub

**Organização**

Os arquivos estão organizados individualmente, de Algoritmo61.kt até Algoritmo70.kt, dentro da pasta src/main/kotlin.

Cada arquivo contém o enunciado, o código original em Portugol e sua conversão para Kotlin.
